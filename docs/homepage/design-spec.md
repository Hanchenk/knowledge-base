# 官网首页设计规格

本次需求来自用户：模仿 https://todayai.cn/ 页面，为平台制作官网首页。当前工作目录为 knowledge-base；README 和现有前端确认产品名称为「知汇 Atlas · 企业知识库」。已异步询问平台名称，收到更正前按当前项目准备。此轮交付三个完整、可滚动、可在浏览器打开的首页视觉初稿，选定后再接入正式 React 首页。沿用项目真实 Logo 与产品截图。

官网面向企业负责人、知识管理负责人和使用 AI 的业务团队。访客应先理解「把企业散落的知识转化成有来源的答案」，再理解知识空间、问答、创作和企业控制能力，最后进入平台或了解部署方式。主要转化为「进入平台」，链接指向当前服务根路径；不提供并不存在的注册流程、销售邮箱、免费套餐或下载客户端。

参考站已通过真实浏览器查看，其首页包含轻量顶栏、居中主标题、低饱和光影背景、半透明产品预览、大面积留白与按记忆/主动性/能力组织的叙事。迁移的是整体气质、排版节奏和产品先行的表达方式，不复用 Today 的商标、个人助理文案、用户故事、赠送 Tokens 或照片。产品结构由企业知识库自身决定。

页面依次呈现顶栏、产品介绍与互动问答示例、价值说明、知识空间、知识问答、创作台、团队使用场景、企业能力、常见问题、进入平台及页脚。问答示例必须标注为功能演示，与真正模型回答区分；示例切换只在前端本地进行，不发送外部请求。AI 语义问答、图像视频创作需要配置相应模型，这个前提写入 FAQ 和相关区块。MCP / REST 接入、组织与空间权限、引用、私有部署等功能均由 README 验证。禁止编造客户 Logo、客户数、效果百分比、SLA 或安全认证。

方向 A 以参考站为锚点：自然光、暖白底色、居中排版和玻璃产品演示，最贴近用户给出的参考。方向 B 是轻量变体：使用现有品牌蓝与冷白底色，同样的叙事结构，增强与工作台的一致性。方向 C 用深墨底与左右分栏的首屏，突出企业产品的稳定和知识空间结构，正文依然以清晰可读为先。Codex 按技能的弱 runtime 模式执行一主版、两个轻量变体，不启用子代理。

正文至少 14px，辅助标注至少 12px；中文 display 使用本地苹方回退以避免外部字体加载问题，英文 Atlas 使用 Georgia 的衬线对比。桌面以 1440px 宽检查，移动端覆盖 390px 和 320px。无远程 CDN、无构建依赖，Logo 和产品图内嵌，支持单文件打开。支持导航锚点、移动菜单、问答示例切换、FAQ 展开与减少动态效果偏好。先完成浏览器截图和交互验证，再展示三个方向供用户选择。
