# 知小汇与官方 DeepSeek Harness 桌面端

知小汇支持云端执行和已连接的本地设备。通过 dsh-team 插件连接官方 DeepSeek Harness Desktop，网页任务进入桌面端的原生会话，使用桌面端配置的模型、工具、审批、会话持久化与上下文压缩。插件不启动另一套 Harness，不替换官方客户端源码。

## 使用

1. 安装 `dsh-plugin-team-hub-0.1.0-alpha.23.tgz`，完全退出并重启 Harness。服务器需要同时升级到包含新连接接口的版本。
2. 客户端发起：打开「团队项目 → 连接知小汇」，填写知小汇地址、选择工作区，点击「连接知小汇」。浏览器自动打开登录和确认页；确认后插件自动连接，无需配对码。无需先登录 Team Hub。
3. 网页发起：打开「执行位置 → 连接本地」。玻璃按钮通过 `dsh://open` 请求唤起 DeepSeek Harness，同时打开连接窗口，自动发现本机插件。选择工作区后，回到网页确认账号；全程不需要配对码。浏览器可能要求确认打开桌面应用；限制本机发现时，可在连接窗口使用直接连接入口，或从客户端发起。
4. 执行位置面板只展示云端、本地电脑下拉框和「连接本地」按钮。本地电脑无论数量多少都在同一个下拉框内；选项展示电脑名、工作区和在线状态。删除按钮仅在悬停或键盘聚焦时出现，触屏保留可点击入口。删除当前连接后切回云端。列表自动刷新，从该面板发起时，新连接的在线工作区自动选中。提交任务后在该工作区执行，继续对话沿用同一个原生会话。

连接会同步所选工作区的全部已有及后续会话。每轮对话对应一个网页任务，同一原生会话的轮次保留关联。同步内容包括用户可见文本、助手公开回复、工具名称与成功状态；通过 `zhixiaohui_task_plan` 更新步骤，通过 `zhixiaohui_write_artifact` 保存文本成果。隐藏推理、工具原始参数和原始结果、个人模型密钥不会被同步。

桌面原生工具生成的普通文件不会被自动扫描上传。需要网页下载的文件由助手调用成果工具保存，支持 md/txt/csv/json/py，单个文件最多 300 KB。网页的公开回复展示最多 200 条、工具事件最多 300 条，过长单条文本显示节选；完整会话保留在桌面端。

## 执行与断线

- 云端任务继续使用平台原有运行时；本地任务不进入云端 worker 的领取或恢复路径。
- 设备离线时网页任务等待上线。已运行的本地任务继续执行，插件把同步快照、步骤和成果保存到本地 SQLite，恢复连接后重传。
- 网页取消只取消对应任务的原生当前轮或对应排队输入，保留该会话中的其他桌面输入。断线期间取消会在恢复连接后送达桌面。
- 本地工具审批在官方桌面端完成；网页显示等待提示。本地执行使用 Harness 已安装的应用工具；平台应用连接器目前用于云端执行。
- 设备凭据仅能访问当前设备的任务桥接接口。授权资料检索仍经过平台账号、任务与资料权限检查。解除连接会撤销凭据并取消对应未完成网页任务。
- 本地失败或暂停的任务在桌面端继续，或在网页提交新任务；网页不会重试原生副作用。

## 实现

后端使用 `bot_devices`、`bot_connections`、`bot_local_execution` 记录账号绑定、网页确认请求和原生会话映射。插件先生成本机专用设备凭据，服务器只存凭据哈希；网页只接收十分钟有效的请求 ID，登录并明确确认账号与工作区后绑定设备。重复确认与轮询幂等；客户端取消连接使请求失效并撤销已批准设备；停用账号、过期请求、错误凭据均无法激活。旧配对 API 保留供旧版插件使用，新版界面不展示配对码。

设备同步仍主动轮询服务器；本机 `127.0.0.1:18765–18769` 中第一个空闲端口只服务连接页面。发现接口仅返回存在性与连接状态，不返回工作区、凭据或会话；工作区选择页禁止 iframe 嵌入，提交需本机 Origin 与一次性 nonce。部署的 CSP 仅新增这五个回环地址用于发现。多 profile 同时运行时各自使用空闲端口，网页显示可选客户端。

插件私有目录中的 `zhixiaohui.sqlite` 保存可撤销设备凭据、待确认请求和持久队列。首次连接与每分钟扫描所选工作区，原生会话事件及公开流式文本触发增量同步。插件默认每两秒同步，优先派发网页任务，再补传工作区历史。

网页入口：`http://192.168.1.34:18088/app?view=bot`。本地 HTTP 限可信内网；公网服务器地址要求 HTTPS。

## 验证范围

官方 **DeepSeek Harness Desktop 0.2.0-rc.2** 的配套运行时，隔离 profile、工作区与测试 API 已完成端到端验证：网页任务派发、本地真实 bash 执行、桌面发起会话回传、公开流式回复、步骤与成果上传下载、网页取消原生执行。测试使用模拟模型适配器，没有调用真实模型，也没有采集用户现有工作区。

插件已通过宿主加载/卸载、历史补传、断线重传、重启恢复、任务去重、成果更新与上传并发等测试；后端权限与 PostgreSQL/Qdrant/MinIO 集成测试通过。网页 15 项 bot 浏览器测试及生产构建通过。Electron GUI 和 Windows 端尚未进行本次自动化验收。以上为 alpha.22 的历史验证，结构化记录见 `bot-local-bridge-verification.json`；alpha.23 的本次验证另记于 `bot-connection-verification.json`。
