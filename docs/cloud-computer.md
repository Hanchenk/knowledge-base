# 云端电脑使用说明

在知小汇 bot 右上角点击「云端电脑」可以连接或断开个人环境、打开任务历史，并查看和下载成果文件。提交云端任务也会自动连接，不需要先手动启动容器。

空闲 30 分钟后自动释放容器；服务器每分钟检查一次。后台刷新页面状态不会维持连接。用户操作与运行中的任务会续期，排队或运行任务期间不能手动断开。

再次连接后，已安装插件、启停状态、加密配置、平台会话、原生会话目录和工作文件继续保留。插件修改在下次任务启动时生效；任务仍需要明确选择要使用的插件。

文件入口使用现有 MinIO / S3 成果存储和应用授权接口。文本、PNG/JPEG/GIF/WebP 图片、PDF 支持在线预览，其他成果支持下载。无需连接容器即可访问已保存的成果。知识库授权撤销或文档版本变化后，相关旧会话和文件会重新校验权限。

自动导入在任务执行完成后发生，支持常见文档、表格、演示稿、图片、文本、代码和 ZIP。当前限制为单文件 5 MB、每次共 30 MB、最多 30 个文件；超过限制会在回答中提示，文件本身仍保留在个人工作目录。不要把隐藏目录或符号链接当作导出入口。

管理员在「设置 → 云端服务」查看引擎版本、服务状态和同步 npm 最新发布版本。普通插件页面不再展示内部引擎与版本控制。

建议为 PostgreSQL、Harness 持久卷和 MinIO 制定一致的备份策略，并在后续增加账号存储配额、容量告警及文件保留期限。30 分钟回收只节省运行资源，不会自动删除持久数据。

运行边界和部署参数详见 [Harness 云端运行与插件](harness-cloud.md)。
