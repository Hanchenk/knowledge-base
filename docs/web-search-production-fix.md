# 联网搜索生产修复

2026-10-12 发布 `web-search-20261012-135500`。[打开知小汇 bot](http://192.168.1.34:18088/app?view=bot)，刷新后输入栏直接显示「联网搜索」开关。

原问题是选择搜索插件并未开启任务的 `allow_web`。生产最近 8 个任务均保存为 `false`，包括已经选择 AnySearch 的任务；因此系统提示写入联网不可用，原生及平台搜索工具都被过滤。服务器与实际任务容器访问 Bing RSS、公开网页均返回 200，AnySearch 无配置即可匿名搜索。

修复将联网入口直接放到输入栏，显示开启、关闭或不可用状态。新加入明确的搜索或抓取插件时，仅在管理员允许联网的云端任务中开启；用户之后手动关闭、恢复旧任务和选择普通插件均不会强制开启。后端的明确关闭联网权限仍保留。

8 项插件页面回归、前端生产构建和格式检查通过。真实生产 Worker/官方 Harness SDK/Docker 执行了匿名 AnySearch 搜索，返回 GitHub 官方仓库等公开 URL；同时验证关闭联网时工具仍被过滤。本轮使用本地模型 fixture，未调用付费模型，也未创建业务任务。

生产浏览器以真实管理员认证，验证了直接开关、提交 `allow_web:true`、390px 手机布局及注销。验证账号没有安装搜索插件，选插件联动由隔离页面回归与真实原生插件运行共同覆盖；任务提交在浏览器拦截，未发送到业务执行接口。
