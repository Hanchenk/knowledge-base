# 创作台与媒体模型

侧边栏「创作台」由 Pi Agent Core 主导对话与工具选择。主智能体复用「设置 → 问答与检索」的问答模型，需要启用 Pi、支持流式 `/chat/completions` 与工具调用的模型；生图、视频服务由 Rust 工具单独调用。Node 子进程只接收问答模型密钥，不接收媒体模型密钥。

## 配置与使用

1. 管理员进入「设置 → 生图与视频」，填写生图或视频服务 Base URL（通常含 `/v1`）与 API Key。页面等待输入稳定后自动读取模型列表；也可刷新或切换手填。
2. 选择支持对应生成接口的模型。服务商列表可能混合问答、向量、图片和视频模型，列表存在不代表支持选定用途。
3. 「测试连接」验证 `/models` 可访问与所选 ID 存在，不提交付费生图或视频任务。服务不提供模型列表时，可手填模型后直接在创作台验证生成能力。
4. 勾选「启用」并保存。主智能体与媒体服务可使用不同地址、密钥。保存立即生效，密钥按企业加密存储且不回传浏览器；旧三项模型配置的读取与保存保持兼容。
5. 在创作台选择生图 / 视频 / Agent 自主选择，切换启用的模型配置，设置画幅与时长，描述画面、风格和用途。Pi 组织提示词后调用生成工具，页面展示工具记录、任务进度与作品；支持继续创作和下载。

创作台采用居中输入卡片，底部统一保留创作类型、模型选择、生成参数、联网与发送入口。「模型」浮层切换启用的配置，「参数」浮层设置图片画幅、视频画幅及时长；浮层不占用输入框排版空间，切换三种模式时框高保持一致。「智能」模式即 Agent 自主选择，可在模型浮层分别指定生图与视频配置。浮层支持点击外部、关闭按钮或 Esc 关闭，Esc 与关闭按钮会将焦点还给原入口；窄屏自动调整工具栏，浮层按可用空间显示在入口上方或下方。

灵感卡片只填入示例提示词，不自动提交生成请求。下方「最近作品」从当前账号最近 8 个项目读取，每个项目最多展示 4 个作品；可放大图片、播放视频、下载或打开项目继续创作。失败任务在项目的「作品与任务」中查看，创作对话可展开查看工具记录与引用。桌面创作记录默认收起，可点击左上角图标展开；手机通过顶部创作记录选择器切换。

创作对话使用与作品区对齐的独立折叠面板，用户消息靠右、助手回复靠左；用户头像显示姓名末字，助手使用产品 Logo。正文收窄阅读宽度并自动换行，引用资料与工具记录归属于对应回复，工具成功 / 失败同时显示文字与图标。标题支持鼠标及键盘展开 / 收起，手机使用相同的消息结构。

联网素材检索默认关闭，勾选后也受管理员 `AGENT_WEB_ENABLED` 策略控制。知识工具沿用当前账号的实时访问权限；主智能体被要求未经用户明确要求不要把企业内部资料发给外部生成服务。

每企业最多保存 40 组生图 / 视频配置，每组独立的名称、模型 ID、Base URL 和 Key，可添加、停用、移除及设为默认。成员只能选择本企业已启用的配置，不能提交任意服务地址 / Key；模型选择按账号保存在当前浏览器，其他账号的选择独立。Agent 自主选择模式可分别指定生图和视频配置。

旧单模型配置会兼容显示为「默认生图模型 / 默认视频模型」，密钥继续保留，GET 不改数据库 revision；保存时加密写入新的多配置结构。旧客户端省略模型目录时不删除已有配置。密钥按稳定配置 ID 保留，重排或重命名不会串用；新的 ID 不继承其他配置密钥。移除配置不删除已生成作品，已提交任务使用原加密快照。

作品图片可点击打开大图预览，支持放大 / 缩小、适应窗口、原始尺寸、滚动查看与下载，Esc 或关闭按钮退出；预览仍通过原作品鉴权接口。作品区支持按图片 / 视频筛选、按提示词搜索，以及将自己的图片作品作为参考图继续创作。

## 参考文件与图片编辑

输入卡片支持选择文件、拖入文件，以及直接粘贴剪贴板图片 / 文件；普通文本粘贴保持原有行为。每次最多 8 个文件，单个文件最多 20 MiB，TXT / Markdown / CSV / JSON 最多 2 MiB 且使用 UTF-8。支持 PNG、JPEG、WebP、PDF、DOCX、PPTX、XLSX 和上述文字文件。图片上限为 2500 万像素，上传完成前或上传失败时禁止提交，失败文件可以重试。

图片作为参考素材传给媒体服务；带旋转或镜像 EXIF 的 JPEG 在上传时通过现有 Pillow 规范化为浏览器显示的方向，让原图与遮罩使用一致坐标。普通 JPEG 保留原字节，规范化图片重新核验文件大小与像素上限。文档复用现有 Python 解析器提取文字；扫描 PDF 需配置视觉模型，视觉页与文字页分别计数。文件内容作为不可信参考资料使用，不能覆盖系统权限。单份文档提取前 16000 字，每轮提供前 8000 字，较长内容请拆分。上传不会把文件加入共享知识空间或向量索引。参考文件仅当前账号可读；未使用文件移除后释放存储，已用于创作的文件保留在私有记录中。

图片功能包括 AI 抠图、擦除、标记改图、扩图和清晰增强。擦除 / 标记改图可打开画笔选区，调整笔刷、撤销、清空并保存；遮罩在浏览器按原图尺寸生成，透明区域交给模型编辑。服务端核验遮罩为带 Alpha 的 PNG，并与第一张参考图同尺寸。抠图请求透明背景，扩图使用选择的目标画幅，清晰增强通过模型编辑提升细节，输出尺寸由当前模型参数控制。

12 种风格包括人像摄影、电影写真、中国风、动漫、3D 渲染、赛博朋克、CG 动画、水墨画、油画、古典、水彩画和卡通；质量可选自动 / 低 / 中 / 高。提示词助手提供可修改的主题、场景、构图与文案结构，文本草稿按账号保存在本机浏览器。

有参考图时使用 OpenAI 兼容 `/images/edits`，无参考图时使用 `/images/generations`。实际支持参考图数量、透明背景、质量和选区编辑的能力取决于所选服务商；模型列表存在不保证编辑能力。接口失败会显示真实失败状态，不会改用文生图再次付费提交。图生视频支持一张参考图：OpenAI 兼容协议使用 `input_reference`，Grok 使用 `image.url` Data URI。暂未提供视频剪辑、音频生成或视频 / 音频附件解析。

## 支持的上游协议

| 用途 | 接口与数据 |
| --- | --- |
| 自动模型列表 | `GET {base_url}/models`，Bearer Key（可无 Key）；读取 `data[].id` 或 `models[].name` / 字符串，去重排序 |
| 生图 | `POST {base_url}/images/generations`，JSON `model,prompt,size,n=1`；读取 `data[0].b64_json` 或 `data[0].url` |
| 参考图 / 图片编辑 | `POST {base_url}/images/edits`，multipart `model,prompt,size,n=1,image`（多图 `image[]`），可选 `mask,quality,background=transparent` |
| OpenAI / Sora 视频提交 | `POST {base_url}/videos`，multipart `model,prompt,size,seconds`；响应必须包含 `id` |
| Grok 视频提交 | 模型 ID 以 `grok-imagine-video` 或 `grok-video` 开头时，使用 `POST {base_url}/videos/generations`，JSON `model,prompt,duration,aspect_ratio,resolution`；优先读取 `request_id`，兼容 `id` |
| 视频进度 | `GET {base_url}/videos/{id}`，读取 `status` 与 `progress` |
| 视频成片 | `GET {base_url}/videos/{id}/content`，MP4 或 WebM 二进制；Grok 接口返回 404/405 时可使用完成响应中的 `video.url` 下载 |

图片尺寸：1024×1024、1536×1024、1024×1536、1792×1024、1024×1792；视频尺寸：1280×720、720×1280；时长：4、8、12 秒。实际可用尺寸取决于所选模型，接口拒绝时会显示生成失败。

Grok 的 1280×720 / 720×1280 分别提交 `aspect_ratio=16:9 / 9:16`，`resolution=720p`，`duration` 使用页面所选秒数。Sub2API 的 Grok 中转接口采用这一 JSON 协议，无需修改已有模型配置。视频状态支持 queued、in_progress、processing、running、pending、completed、succeeded、done、failed、cancelled/canceled、expired。不同厂商自有任务路径、签名、模型列表、参数或响应格式需要增加适配器；填写任意 URL 不代表自动兼容全部服务商。

成片代理请求携带配置的 Bearer Key；服务商返回的下载 URL 不携带模型 Key。同源 URL 使用管理员已配置的服务地址，其他来源经过公网地址校验并限制下载大小。协议按模型 ID 选择，不在提交失败后切换接口重提，避免重复生成与计费。

## 持久化、权限与故障处理

新增 schema version 3 的 `studio_projects/messages/jobs/assets` 表，启动时自动建表，不迁移现有知识库与模型数据。开发模式沿用 SQLite / 本地文件；生产沿用 PostgreSQL / MinIO，作品不存进知识向量索引。

API 的 `WORKER_ENABLED=true` 启动两个媒体 Worker；生产使用已有独立 `atlas-server --worker`，同时运行索引与媒体任务。若 API 关闭内置 Worker，必须启动独立 Worker 才会生成作品。API / Worker 需使用同一数据库、对象存储和模型加密密钥。

项目、消息、任务和作品仅创建者的有效浏览器账号可读取，管理员也不能读取其他人的创作。媒体接口逐次鉴权，支持单字节范围请求以便视频播放；配置接口仅管理员可用。首版未开放创作 API Key / MCP 工具给平台外 Agent。图片上限 20 MB，视频上限 200 MB，文件按实际格式签名校验。

同一项目的 `request_id + kind` 唯一，每轮每种类型只创建一个任务；Agent 重复工具调用与浏览器原样重试复用该任务。同一 UUID 的提示词、参数、参考文件顺序和遮罩在首次提交时固定，变更后返回 HTTP 409，需分配新请求。主动继续创作会分配新请求并可能再次计费。提交时带 `Idempotency-Key`，上游是否支持由服务商决定。

Worker 通过原子领取与五分钟租约避免重复执行；视频正常每五秒查询，最多持续 45 分钟。查询或下载遇到网络失败、HTTP 408/429/5xx 时最多连续重试六次，仅重试读取，不重提生成；401、格式不兼容和最终生成失败会停止。已有服务商视频 ID 时，重启后继续查询；提交结果不确定且没有 ID 时，将任务标记为需人工核对，不自动再次提交付费请求。失败任务不自动重提，重新创作前应核对服务商记录。生成配置快照加密保存，完成或最终失败后清除任务中的加密配置。

## 平台接口

- `GET /api/studio/capabilities`：当前企业的 Agent 与创作能力。
- `GET/POST /api/studio/projects`：读取自己最近项目 / 新建项目。
- `GET /api/studio/projects/{id}`：项目、授权对话、任务与作品元数据。
- `POST /api/studio/chat`：带 UUID `request_id` 提交 Pi 创作请求。
- `GET /api/studio/assets/{id}`：鉴权后预览 / 播放 / 下载作品，支持 Range。
- `POST /api/studio/attachments`：multipart 单个 `file` 上传私有参考图 / 文档。
- `GET/DELETE /api/studio/attachments/{id}`：读取私有参考文件 / 移除未使用文件。
- `POST /api/studio/assets/{id}/reference`：把自己的图片作品复制为参考图。
- `POST /api/models/discover`：管理员获取当前服务商的模型列表。

完整字段与状态码见 [OpenAPI](openapi.json)。验证使用隔离模型服务与真实 Pi SDK；真实服务商的生成质量、额度、耗时和协议兼容性需配置后另行验收。

图片与文档附件、创作请求关联和操作参数通过 schema version 12 的独立表持久化，启动自动迁移，兼容原有任务。专项测试验证跨账号 / 跨企业隔离、文件类型和大小、Office 文件解析、原图与遮罩传递、全部 8 种 EXIF 方向的真实像素与遮罩尺寸、质量和风格、请求输入冻结、编辑失败不回退，以及 OpenAI / Grok 图生视频参数。浏览器测试覆盖粘贴 / 拖拽 / 重试、作品复用、选区画笔、草稿恢复和手机布局。
